# Asset folders

All imagery is wired through `src/config/assets.js`. To replace an image, drop the file
into the matching folder below and change its `src` in that config — no component edits needed.

- `logo/` — official BMS Heights / SKD Developers logo (not supplied; the site uses a text wordmark)
- `architecture/` — official renders / photographs of BMS Heights
- `interiors/` — sample-flat or finish photography
- `floor-plans/` — approved floor plan artwork (the site currently shows labelled conceptual diagrams)
- `amenities/` — amenity renders
- `gallery/` — gallery imagery

Current images are illustrative stock photography (Unsplash licence) and are labelled as such on the site.
They are NOT photographs of BMS Heights.
